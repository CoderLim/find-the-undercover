# 添笔成词题库扩充设计

## 目标

在 `data/puzzles.js` 现有 54 道题基础上新增 50 道，使题库达到 104 道。

## 题目规则

- 每个基础字只能增加 1、2 或 3 笔。
- `word` 必须等于左右两个答案字拼接后的结果。
- 最终词语在整个题库中不得重复。
- 可以复用已有的“基础字 + 笔画 = 答案字”组合。
- 优先从用户提供的二年级语文词表中选题；不足部分使用同年级常见、具体的词语补足。
- 每题保留明确的加笔说明。

## 随机与去重

继续使用 `utils/used-picker.js` 的未使用索引池。每次从当前未使用题目中随机选择，完整抽完 104 道前不重复；题库用尽后开启新一轮。

## 校验

- 自动校验题库数量为 104。
- 自动校验字段、加笔数、答案拼词关系和最终词唯一性。
- 自动校验完整抽取一轮时 104 个索引均不重复。
- 更新 README 中所有题库数量说明。
